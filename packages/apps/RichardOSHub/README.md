# RichardOS Hub

Initial privileged system-app skeleton for RichardOS.

## Current implementation
- Home screen with four feature areas.
- Monet palette selection (six curated seed colors).
- Custom hexadecimal accent color saved in app preferences.
- Basic read-only build information.

## Not implemented yet
- Applying palettes to Android's system-wide Monet resources.
- SystemUI status bar and Quick Settings controls.
- Reliable root-manager detection.
- Lock screen integration.

## Build integration
Add `RichardOSHub` to the device/product package list after reviewing the app module and platform branch compatibility.

This is source code, not a flashable ROM or tested APK.
